# outline-github-backup

Break-glass backup for [Outline](https://www.getoutline.com): a webhook service that live-mirrors
your documents (and comment threads) as markdown to a GitHub repo, plus a CLI to backfill,
export, and restore content to any Outline instance.

> ⚠️ Point the destination at a **private** repo unless you want your wiki public.

Status: under construction.
